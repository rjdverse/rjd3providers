# Gets the name of the xml provider.

Gets the name of the xml provider.

## Usage

``` r
xml_name()
```

## Value

The name of the xml provider, to be used in monikers.

## Examples

``` r
xml_name()
#> Error in .jfield("jdplus/text/base/api/XmlProvider", "S", name = "NAME"): cannot find class jdplus/text/base/api/XmlProvider
```
