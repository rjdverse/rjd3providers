# rjd3providers: Interface to 'JDemetra+' 3.x Time Series Analysis Software

Interface to 'JDemetra+' 3.x (<https://github.com/jdemetra>) time series
analysis software. It offers full access to txt, csv, xml and
spreadsheets files which are meant to be read by 'JDemetra+' Graphical
User Interface.
