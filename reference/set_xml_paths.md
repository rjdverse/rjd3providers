# Set the paths to xml files (to be used with relative identifiers).

Set the paths to xml files (to be used with relative identifiers).

## Usage

``` r
set_xml_paths(paths)
```

## Arguments

- paths:

  The folders containing the xml files. Only used in relative addresses.

## Value

No output.

## Examples

``` r

set_xml_paths(system.file("extdata", package = "rjd3providers"))
```
