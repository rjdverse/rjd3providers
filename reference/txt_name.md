# Gets the name of the text provider

Gets the name of the text provider

## Usage

``` r
txt_name()
```

## Value

The name of the text provider, to be used in monikers

## Examples

``` r
txt_name()
#> Error in .jfield("jdplus/text/base/api/TxtProvider", name = "NAME"): cannot find class jdplus/text/base/api/TxtProvider
```
