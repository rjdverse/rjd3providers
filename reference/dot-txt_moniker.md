# Generates a java moniker for the corresponding id.

Generates a java moniker for the corresponding id.

## Usage

``` r
.txt_moniker(id)
```

## Arguments

- id:

  Identifier of the requested information.

## Value

An internal java moniker.

## Examples

``` r
if (FALSE) { # rjd3toolkit::get_java_version() >= rjd3toolkit::minimal_java_version

.txt_moniker("toy_id")
}
```
