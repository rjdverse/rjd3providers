# Gets the name of the spreadsheet provider.

Gets the name of the spreadsheet provider.

## Usage

``` r
spreadsheet_name()
```

## Value

The name of the spreadsheet provider, to be used in monikers.

## Examples

``` r
if (FALSE) { # rjd3toolkit::get_java_version() >= rjd3toolkit::minimal_java_version

print(spreadsheet_name())
}
```
